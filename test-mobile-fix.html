Revision Filter - Mobile Fix Test

Instructions: Resize your browser window to mobile width (≤768px) or view on a mobile device to see the fix in action.

Before Fix (Original Layout):

❌ On mobile, this layout breaks:

  • Checkbox appears in center of screen
  • "Start:" label doesn't wrap properly
  • Form is difficult to use

After Fix (With Mobile CSS):

Expected Behavior on Mobile:

✅ With the fix applied:

  • All labels appear above their inputs
  • "Bots:" checkbox is properly aligned with its label
  • "Start:" and "End:" labels each appear on new lines
  • Form is fully usable on mobile devices
  • Desktop layout remains unchanged

Technical Details:

The fix uses CSS media queries to override the flex layout on mobile devices (≤768px) and implements a vertical stacking layout that's more appropriate for mobile screens.

View CSS Fix 
@media screen and (max-width: 768px) {
  .filter.inline-label.is-condensed {
    display: block !important;
  }
  
  .filter.inline-label.is-condensed > * {
    display: block !important;
    width: 100% !important;
    margin-bottom: 12px;
    margin-right: 0 !important;
  }
  
  /* Special handling for checkboxes */
  .filter.inline-label.is-condensed input[type="checkbox"] {
    display: inline-block !important;
    width: auto !important;
    margin-right: 8px !important;
  }
}
